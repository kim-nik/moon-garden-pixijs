# Лунный сад

Браузерная игра «три в ряд» на PixiJS 8 и TypeScript. Кампания из 180 уровней проходит через шесть глав. За звёзды игрок восстанавливает 12 объектов ночного сада.

## Запустить игру

Установите Node.js 22.12 или новее. Проект проверен с Node.js 24.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite, обычно [localhost:5173](http://localhost:5173). Для production-сборки выполните:

```sh
npm run build
npm run preview
```

Папку `dist` можно разместить на статическом хостинге. Игра работает без сервера данных. Шрифт, рисунки и звук включены в проект; внешние CDN не нужны. Для отображения поля браузеру нужен WebGL.

## Проверить изменения

```sh
npm test
npm run balance
```

`npm test` проверяет правила, усилители, препятствия, сохранения и награды. `npm run balance` проходит всю кампанию агентом без инструментов и сохраняет команды каждого решения в `reports/verification/balance.json`. Он также проверяет начальные поля с альтернативными семенами и повторяет записанные партии.

Для проверки интерфейса оставьте dev-сервер запущенным и в другом терминале выполните:

```sh
npm run smoke
```

На Windows сценарий использует установленный Microsoft Edge. Другой установленный браузер задаётся через `BROWSER_CHANNEL`. На Linux установите Chromium командой `npx playwright install chromium`. Адрес сервера можно изменить через `GAME_URL`.

Сценарий создаёт отдельный профиль браузера, проверяет игру кликами и свайпами, сохраняет снимки экранов и отчёт `reports/verification/browser.json`. Пользовательское сохранение он не затрагивает.

## Играть

Поменяйте соседние растения, чтобы собрать минимум три одинаковых в ряд. Выполните все цели до конца ходов. Неудачный обмен откатывается бесплатно.

Четыре в ряд дают усилитель линии, пять — радугу, пересечение рядов — бомбу. Усилитель запускается двойным нажатием, Пробелом или обменом. Два соседних усилителя можно объединить.

Иней снимается совпадением на клетке. Ящики убираются соседним совпадением или взрывом и перекрывают падение. Лоза удерживает растение до совпадения на клетке, рядом или попадания взрыва. Двойные препятствия требуют двух попаданий.

Лопатка снимает слой препятствия или убирает растение. Перемешивание сохраняет препятствия и усилители. Цветочная волна убирает выбранный цвет. Инструменты расходуют запас, но не ходы. Подсказки бесплатны. При тупике поле перемешивается автоматически.

Для двух звёзд сохраните не менее 15% ходов, для трёх — не менее 30%. Повторная награда выдаётся только за улучшение числа звёзд. Семена также выдаются за восстановление сада. Ежедневное испытание использует фиксированное поле для местной календарной даты и запрещает инструменты.

Стрелки перемещают курсор по полю. Enter выбирает клетку и соседнюю для обмена, Пробел запускает усилитель, Escape снимает выбор или закрывает окно. H показывает подсказку, P открывает паузу.

Прогресс сохраняется в localStorage после принятого хода. В настройках можно экспортировать JSON-файл и импортировать его в другом браузере. Перед очисткой данных браузера сохраните резервную копию.

## Объём кампании

Цель дизайна — не менее пяти часов активной игры. В проверенном прохождении 180 уровней агент сделал около 4500 ходов. При допущении 4–6 секунд на ход это примерно 5–7,5 часа без неудачных попыток, сада и повторов на три звезды.

Это оценка, а не результат человеческого плейтеста. Агент видит результаты возможных ходов и выбирает выгодный вариант. Он не измеряет время размышлений человека и не доказывает среднюю сложность. Локальные результаты проверок сохраняются в `reports/`. Эта папка исключена из Git.
